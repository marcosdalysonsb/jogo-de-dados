## 📌 Sobre o projeto

Este projeto consiste em um jogo de dados desenvolvido com **Expo e React Native**, como atividade acadêmica de desenvolvimento mobile.

A aplicação permite jogar rodadas utilizando dados virtuais, acompanhar a pontuação e visualizar o resultado final da partida. O projeto também faz parte do processo de migração de uma aplicação web para uma aplicação mobile.

## 🎯 Objetivos

- Praticar o desenvolvimento de aplicações mobile;
- Migrar a estrutura de uma aplicação web para React Native;
- Utilizar componentes e gerenciamento de estado;
- Trabalhar com imagens e recursos locais;
- Organizar o código para facilitar a manutenção;
- Utilizar Git e GitHub para controle de versão;
- Utilizar Expo e EAS para gerenciar e publicar atualizações do projeto.

## ⚙️ Funcionalidades

- 🎲 Rolagem de dois dados virtuais;
- 🖼️ Exibição das faces dos dados por meio de imagens;
- 🔢 Geração aleatória de valores entre 1 e 6;
- 🧮 Contabilização da pontuação;
- 🔄 Controle das rodadas da partida;
- 🏁 Encerramento da partida após o limite de rodadas;
- 🏆 Exibição do resultado final;
- 📱 Interface desenvolvida com React Native;
- ✅ Validação dos valores utilizados para representar os dados.

---

## 🧩 Organização do projeto

- **`App.js`** — componente principal da aplicação;
- **`components/JogoDados.js`** — lógica e interface do jogo;
- **`components/Dado.js`** — componente responsável por exibir a face de cada dado;
- **`assets/dados/`** — imagens utilizadas para representar as seis faces dos dados.

## ▶️ Como executar o projeto

### Pré-requisitos

- Node.js instalado;
- npm instalado;
- Expo Go em um dispositivo compatível ou um emulador configurado.

### Instalação

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Entre na pasta do projeto:

   ```bash
   cd jogo-de-dados
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o Expo:

   ```bash
   npx expo start
   ```

5. Abra a aplicação pelo Expo Go ou por um emulador compatível.
